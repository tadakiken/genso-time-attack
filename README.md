# ⚛️ 元素タイムアタック

中学生が **元素記号・化学式・イオン・化学反応式** を楽しく覚えるための、60秒タイムアタック形式の学習アプリです。

▶ **遊ぶ：https://tadakiken.github.io/genso-time-attack/**

インストール不要。スマホ・タブレット・パソコンのブラウザで動きます。

## 遊び方

- 60秒で何問正解できるかに挑戦します。まちがえると正解と解説が表示されます。
- 各レベルで決められた数以上正解すると、次のレベルが解放されます。
- 結果画面に S / A / B / C のランク、ベスト記録、まちがえた問題のふりかえりが出ます。
- 「ずかん」で、出題される元素・物質・反応式をいつでも確認できます。
- パソコンでは数字キー `1`〜`4` で選択肢を選べます。

## レベル

| Lv | 内容 | 形式 |
|----|------|------|
| 1 | 元素記号 にゅうもん（よく出る10種類） | 元素名 → 記号 |
| 2 | 元素記号 マスター（18種類） | 名前 ⇄ 記号 |
| 3 | 元素記号 タイピング | 記号を入力（大文字・小文字も判定） |
| 4 | 元素のせいしつ | ヒント → 元素 |
| 5 | 分子の化学式 | H₂, O₂, H₂O, CO₂, NH₃ など |
| 6 | 化合物の化学式 ① | 酸化物・硫化物・塩化物 |
| 7 | 化合物の化学式 ② | 酸・アルカリ・炭酸の化合物 |
| 8 | イオンの化学式 | Na⁺, Cu²⁺, Cl⁻, SO₄²⁻ など |
| 9 | 化学反応式 | 反応式・電離式の空らんをうめる |
| 10 | ファイナルチャレンジ | 全レベルからランダム |

## 収録している元素（18種類）

中学理科の教科書・高校入試で出てくるものだけにしぼっています。

H（水素）、He（ヘリウム）、C（炭素）、N（窒素）、O（酸素）、Na（ナトリウム）、Mg（マグネシウム）、Al（アルミニウム）、S（硫黄）、Cl（塩素）、K（カリウム）、Ca（カルシウム）、Fe（鉄）、Cu（銅）、Zn（亜鉛）、Ag（銀）、Ba（バリウム）、Au（金）

## 先生・保護者の方へ

- ホーム画面下の「全レベル解放（先生用）」で、すべてのレベルをすぐに試せます。
- 記録はその端末のブラウザ内だけに保存されます（サーバーへの送信はありません）。
- 問題データは `data.js` にまとまっているので、元素や化合物の追加・修正がかんたんです。

## ファイル構成

- `index.html` … 画面
- `style.css` … デザイン
- `data.js` … 元素・分子・化合物・イオン・反応式のデータ
- `app.js` … ゲームの動き

ビルド不要の静的サイトで、GitHub Pages で公開しています。
